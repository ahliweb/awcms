# Design artifacts

Design explorations and UI/UX proposals for AWCMS surfaces. Everything here is
**reference-only design material**: it is not shipped code, it calls no API,
and nothing in it changes runtime behaviour. The canonical design rules remain
[`docs/awcms/14_ui_ux_design_system.md`](../docs/awcms/14_ui_ux_design_system.md)
and [`src/styles/tokens.css`](../src/styles/tokens.css) until a proposal here is
accepted through an ADR.

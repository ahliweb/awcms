feat(identity-access): pure passkey (WebAuthn) verifier for ADR-0168 slice S1 (Issue #1405). Three dependency-free domain files — a CBOR subset decoder, COSE key parsing and signature verification on `node:crypto` (ES256, EdDSA/Ed25519, RS256; no curve or big-integer arithmetic of our own), and registration/assertion verification implementing the ten normative checks of amendment A6 plus the A7 counter decision. Attestation `fmt` is accepted but `attStmt` is never verified or trusted. Ships dark: no endpoint, migration, UI or configuration, and a test fails if anything in `src/` starts importing it; `AUTH_PASSKEY_ENABLED` arrives with the first caller (S3). Covered by the W3C WebAuthn L3 test vectors and 953 Wycheproof vectors (ECDSA P-256 DER including the CVE-2022-21449 class, Ed25519, RSA PKCS#1 v1.5), a red matrix where removing any check fails a test, and fuzz tests. Ed25519 public keys with a non-canonical y (y ≥ p, which the runtime accepts and of which y = p + 1 is the identity) are refused before the small-order blocklist, which is now matched with the sign bit masked (G7 review finding H1). The differential against a reference implementation is only partly done (outside the repo); see the module README.

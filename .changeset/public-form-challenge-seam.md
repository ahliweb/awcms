feat(security): a pluggable, off-by-default, fail-closed challenge (captcha) seam for pre-session forms (Issue #1353, owner decision K9). `enforcePublicFormCaptcha(request, formName, body)` (`src/lib/security/public-form-challenge.ts`) is the one call a public form makes; a module contributes a provider from its descriptor (`publicFormChallengeProviders`, module contract 4.8.0, ADR-0164's model). A verifier error, timeout or any result other than `{ ok: true }` refuses the request; a presented token is burned per process before it is verified (single use, bounded); every refusal other than "nothing presented" is one response (no oracle). Cloudflare Turnstile is the first provider and its seven former call sites (login x2, register, forgot, reset, invitation accept, setup) now go through the seam, so there is one path; its published contract (`turnstileToken`, `TURNSTILE_REQUIRED` / `TURNSTILE_INVALID`) is unchanged and the neutral `challengeId` / `challengeAnswer` / `challengeToken` fields are read as well (optional fields added to the OpenAPI bodies). New client helper `src/lib/ui/public-form-challenge-client.ts`; `/reset-password` now renders the Turnstile widget (it could not complete a reset when Turnstile was on); the integration harness `invoke()` supplies a solved challenge by default (`challenge: false` opts out). `extension-points:check` validates the declarations and refuses a direct `enforceTurnstileIfRequired` call outside its own files. No migration; default behaviour unchanged.

Audit follow-up (same change): the seam is now fail-closed in a process with no extension-point source (it refuses; a `bunfig.toml` test preload installs the source for tests); a configuration fault is refused with the triggering provider's own refusal text; burn keys are length-prefixed; a test solver is registered with `registerPublicFormChallengeTestSolver` (test-only) instead of being a descriptor field; the `extension-points:check` rule is now on imports of `enforceTurnstileIfRequired` / `verifyTurnstileToken` (aliases, namespace imports, re-exports and dynamic imports included; `website-engagement` is a recorded exception). Turnstile breaker: only Cloudflare-side failures (5xx, 408/429, unparsable 2xx, `internal-error`) count; bad tokens, other 4xx and `invalid-input-secret` never open it.
